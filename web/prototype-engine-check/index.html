Can a browser build this book?

Prototype for ticket 01 of the WASM scenario builder map. It is throwaway code that answers one question and nothing else.

The question. A WebAssembly TeX engine runs inside this tab. No server compiles anything. Can that engine build this book's preamble, and then a whole scenario, the way tools/build.sh -s builds it locally? Three steps, smallest first: a trivial document, then metadata.tex with its 40 packages, then one real scenario.

Engine: TeXlyre BusyTeX, LuaHBTeX, TeX Live 2026, AGPL-3.0. Data package texlive-extra, which is 326 MB, on top of 31 MB of engine. The smaller texlive-recommended was tried first and is not enough: it has no adjustbox and no pgf-blur. Loading takes a few minutes the first time.
