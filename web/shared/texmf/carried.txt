# TeX Live files the scenario builder carries, because texlive-basic, the
# data package the app preloads, lacks them. carry-texmf.mjs builds
# carried-texmf.bin and carried.lock.json from this list; see its header.
#
# One "<source> <path>" per line:
#   texlive-extra <path>  copied out of the pinned engine's texlive-extra.data,
#                         so it matches the TeX Live release of texlive-basic
#   ctan <file>           a file under ctan/, which no data package ships;
#                         fetch-missing-texmf.sh downloads it
#
# Found by building scenarios from every category, plus a Russian one, on the
# real engine, and adding every file a build missed. Each group says why the
# book reads it; the metadata.tex line numbers name the \usepackage.
#
# Each file lands flat in the working directory, so two entries must never
# share a basename.
